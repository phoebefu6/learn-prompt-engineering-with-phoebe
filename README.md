# learn prompt engineering with phoebe

An interactive, two-track course on prompt engineering - built for 2026, not 2023.

**Live site:** https://phoebefu6.github.io/learn-prompt-engineering-with-phoebe/

## Two tracks, one course

| Track | For | Sessions | Focus |
|-------|-----|----------|-------|
| **For Leaders** | C-level, boards, managers, curious non-tech folks | 6 x 45 min | Thinking mode: how to ask the right question, judge the output, and work with your data/tech team to get ideas shipped |
| **For Builders** | Practitioners who write prompts for systems | 10 x 45 min | The craft end to end: techniques, reasoning models, long context, agentic prompting, vendor deltas, evals, security |

Both tracks follow one company - Meridian Retail - from "the AI is useless" to shipped, evaluated, secured prompt systems. Builders grow one artifact, TriageBot, across all ten sessions.

## What makes it current

- Reasoning models inverted the classic advice (no more "think step by step") - the course teaches the decision tree, not the folklore
- Prompting framed as a layer inside context engineering
- Evals treated as the core practitioner skill, not an afterthought
- Security session built on the injection vs jailbreak distinction, the lethal trifecta, and OWASP 2025
- Vendor deltas taught honestly: where Anthropic, OpenAI, and Google agree, and where they openly disagree

Coverage maps to real, verified sources (Anthropic docs + interactive tutorial + courses, OpenAI guides, Google's prompting whitepaper + Gemini docs, DeepLearning.AI syllabi, foundational papers) - see `materials/official-course-map.md`. Official certificates and videos stay with the vendors; this course teaches the working content.

## Format

Static HTML/CSS/JS, no build step. Each session: concept accordions (Live vs Self-study), inline SVG diagrams, build-along on real work, homework, a 3-question quiz, honest source-coverage rows, and a cheat sheet. Presenter run-of-show lives in `materials/`.
